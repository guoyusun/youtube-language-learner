# 🎧 LinguaTube · YouTube 外语字幕提取与单句复读学习台

一个专为外语学习者（听力精听、Shadowing 影子跟读、视译复述、词汇积累）设计的本地网页应用。  
输入任意 YouTube 视频或 **YouTube Shorts** 链接，即可自动提取**词级毫秒时间戳**并拼装为**完整自然的句子**，与视频同屏互动学习。

---

## 📦 一、如何安装与启动（Installation）

### 1. 环境准备
电脑上只需安装有 **Python 3.9 及以上版本** 和 **Git**：
- **macOS**：打开终端运行 `python3 --version` 检查；若未安装可通过 `brew install python` 或前往 [python.org](https://www.python.org/downloads/) 下载。
- **Windows**：前往 [python.org](https://www.python.org/downloads/) 下载安装（安装时勾选 **"Add Python to PATH"**）。

---

### 2. 下载并一键启动（推荐）

#### 🍎 macOS / Linux 用户
打开终端（Terminal），依次执行以下命令：

```bash
# 1. 克隆仓库到本地
git clone https://github.com/guoyusun/youtube-language-learner.git

# 2. 进入项目目录并运行一键启动脚本（首次运行会自动创建虚拟环境并安装依赖）
cd youtube-language-learner
./start.sh
```

#### 🪟 Windows 用户
打开命令提示符（CMD）或 PowerShell，依次执行：

```bat
:: 1. 克隆仓库到本地
git clone https://github.com/guoyusun/youtube-language-learner.git

:: 2. 进入目录并运行启动脚本（或直接在文件夹中双击 start.bat）
cd youtube-language-learner
start.bat
```

---

### 3. 手动安装与启动（可选）
如果你不想使用一键脚本，也可以手动创建虚拟环境并启动：

```bash
# 1. 创建 Python 虚拟环境
python3 -m venv .venv

# 2. 激活虚拟环境并安装依赖
# macOS / Linux:
source .venv/bin/activate
# Windows:
# .venv\Scripts\activate

pip install -r requirements.txt

# 3. 启动本地服务（默认端口 8765）
python server.py
```

启动成功后，在浏览器访问：👉 **[http://127.0.0.1:8765](http://127.0.0.1:8765)**

## 📖 二、如何使用（How to Use）

### 1. 提取视频字幕
1. 在页面顶部输入框粘贴任意 YouTube 链接（支持标准视频 `youtube.com/watch?v=...`、短链 `youtu.be/...` 以及竖屏短视频 `youtube.com/shorts/...`）。
2. 点击 **「提取字幕并加载」** 按钮。
3. 右上角可切换：
   - **原文字幕**：选择视频自带的不同语言字幕轨。
   - **双语对照**：默认开启 `中文 (简体)` 自动对齐翻译，也可切换为日语、韩语、西语、法语或关闭翻译。
   - **断句模式**：
     - **智能完整长句 (推荐跟读)**：利用 YouTube 底层 `json3` 词级毫秒时间戳，自动将跨行碎词合并为完整长句，并将短设问（Q&A）智能成组。
     - **标准按标点断句**：严格按照真实句末标点（`.`、`?`、`!`）切分完整语法句。
     - **原始碎片时间轴**：保留 YouTube 原生 2~3 秒一行的短字幕。

---

### 2. 点击跳转 & 单句循环跟读（Shadowing 练习）
- **点击字幕即刻跳转**：点击右侧字幕列表中的任意一行（或点击行末的 `▶ 播放`），视频立即跳转到该句的精确起始时间播放。
- **单句循环复读 (`🔁`)**：
  - 点击任意字幕行右侧的 **`🔁 复读此句`**（或按键盘快捷键 **`L`**），播放器会锁定该句无限循环播放。
  - **复读策略**：在左下角控制栏可设置为 `∞ 无限单句循环`，或 `2遍 / 3遍 / 5遍后自动下一句`（逐句推进跟读）。
  - **跟读留白暂停**：可选择 `句末停顿 1.5 秒`、`3.0 秒` 或 `按原句时长 1:1 留白`。每句播完后视频会自动暂停相应时长，留给你开口跟读，随后自动重播或进入下一句。
  - **播放倍速**：支持 `0.5x`、`0.75x`、`0.9x`、`1.0x`、`1.25x`、`1.5x` 多档变速。

---

### 3. 照着复述 / 视译回译训练（显隐控制按钮）
在右侧工具栏（以及左侧当前句卡片右上角）提供两个独立显隐开关：
- **看着中文复述英文（回译练习）**：点击 **「👁️ 显示原文」**（快捷键 **`O`**）将其切换为 **`🙈 隐藏原文`**。此时英文原文完全收起，中文译文字号自动放大高亮，方便看着中文口头复述英文。
- **看着英文专注跟读**：点击 **「👁️ 显示译文」**（快捷键 **`T`**）将其切换为 **`🙈 隐藏译文`**。此时中文翻译完全收起，避免视线受中文干扰。
- **纯盲听训练**：同时隐藏原文与译文（或直接按快捷键 **`B`**），字幕变为毛玻璃遮罩状态；鼠标悬停在某一行字幕上即可临时显形核对。

---

### 4. 点词查音、生词本与字幕导出
- **即点即读 & 查词**：直接点击字幕中的**任意英文单词**，浏览器会自动朗读该单词发音，并弹出快捷查词卡片（一键直达有道词典、Cambridge 词典、Google 翻译或加入生词本）。
- **生词与重点句收藏**：点击左侧当前句面板的 `⭐ 收藏本句` 或单词卡片的 `➕ 加入生词本`，可在右上角 **「📒 生词与重点句」** 抽屉中随时复习、跳转复读或导出为 Markdown 笔记。
- **一键导出字幕**：点击右上角 **「📥 导出 / 复制字幕」**，支持：
  - 复制纯文本字幕
  - 复制带时间戳字幕
  - 复制双语对照文本
  - 下载 `.SRT` 字幕文件
  - 下载 `.md` Markdown 学习笔记

## ⌨️ 三、全键盘快捷键一览

在页面非输入框状态下，可直接使用键盘控制跟读：

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Space` (空格)** | 播放 / 暂停视频 |
| **`←` 或 `A`** | 跳转到**上一句**字幕并播放 |
| **`→` 或 `D`** | 跳转到**下一句**字幕并播放 |
| **`S`** | 从头**重播当前句** |
| **`L` 或 `R`** | 开启 / 关闭 **单句循环复读** |
| **`O`** | 显示 / 隐藏 **原文文本**（方便看着译文回译复述） |
| **`T`** | 显示 / 隐藏 **译文文本**（方便专注看原文跟读） |
| **`B`** | 开启 / 关闭 **盲听遮罩**（同时遮盖原文与译文，悬停可看） |

## ❓ 四、常见问题（FAQ）

1. **为什么换了端口或提示 `Address already in use`？**
   - 默认运行在 `8765` 端口。可通过环境变量自定义端口启动：`PORT=9000 ./start.sh`。
2. **提示无法获取字幕怎么办？**
   - 请确认该 YouTube 视频是公开视频且包含字幕（或自动生成字幕），同时确保当前电脑网络可以正常访问 YouTube。
3. **代码更新后如何在另一台电脑同步？**
   - 在项目目录下运行 `git pull` 即可拉取最新代码。
