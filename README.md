# LinguaTube · YouTube 外语字幕提取与单句复读学习应用

一个专为外语学习者（听力精听、跟读 Shadowing、词汇积累）设计的本地网页应用。输入任意 YouTube 视频或 **YouTube Shorts** 链接（如 `https://www.youtube.com/shorts/_hgYfOs9rbs`），即可自动提取字幕时间轴并与视频同屏互动学习。

## ✨ 核心功能

1. **自动提取 YouTube / Shorts 字幕与双语对照**
   - 支持所有标准 YouTube 链接、`youtu.be` 短链以及 `youtube.com/shorts/...` 竖屏短视频链接。
   - 双引擎保障：优先使用 `youtube-transcript-api` 高速获取官方/自动生成字幕与多语言翻译，并内置 `yt-dlp` 兜底提取。
   - 对重叠时间戳进行智能切分校准，确保单句复读边界精准不串句。

2. **点击字幕跳转 & 单句循环复读（Shadowing 跟读利器）**
   - **点击即跳**：点击右侧字幕列表中的任意一行，视频立即跳转到该句起点播放。
   - **单句循环 (🔁)**：一键锁定当前句子无限循环，或设置为 **循环 2 / 3 / 5 遍后自动跳到下一句**。
   - **跟读留白暂停**：可设置句末自动暂停 `1.5秒`、`3.0秒` 或 `按原句时长 1:1 留白`，留出开口跟读时间后再进入下一遍复读。
   - **多档变速**：支持 `0.5x` ~ `1.5x` 播放倍速切换。

3. **盲听遮罩 & 点词发音查词**
   - **盲听模式 (`B` 键)**：一键模糊遮盖字幕文本，先练听力，鼠标悬停即可查看原文。
   - **即点即读**：点击字幕中的任意单词即可调用浏览器语音朗读，并快速跳转有道词典、剑桥词典、Google 翻译或加入本地生词本。

4. **一键导出字幕与学习笔记**
   - 支持复制纯文本、带时间戳文本、双语对照文本，以及直接下载 `.SRT` 字幕文件和 `.md` Markdown 学习笔记。
